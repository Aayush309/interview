## Getting Started

- This application was made using the Flutter framework. 
- As per the requirement no state management tool was used and only used setState().
- This app will run on both mobile platforms in Android and iOS and web framework.
- The tap changes the mood in a random manner changing the emojis and the data on the screen.
- Used the hugeIcons package for icons
- 
# How to run the application

- You are required to have the flutter sdk and the Android Studio in your machine to run this code.
- Hit **flutter pub get**
- Clone or download this repo and put it in the folder where you wish to store it.
- Once it is on your device open android studio turn on emulator or connect to physical device
- And Click on the Run button on the top
- If it is not running use the command **flutter run** in the treminal

## Project structure

- `lib/main.dart`: app entry point and the mood card screen.
- `lib/mood.dart`: the `Mood` model and the list of moods.
